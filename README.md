# پنل معلم روی Runflare (Node.js)

همان `index.js` کلودفلر است (فایل `worker-src.js`) بدون هیچ تغییری؛ `server.mjs` فقط آن را روی Node اجرا می‌کند.
فونت‌ها و کتابخانه‌ها (PDF، Excel، OCR فارسی) داخل پوشه‌ی `public/_lib` هستند و به اینترنت بین‌الملل نیاز ندارند.

## راه‌اندازی
1. محتویات این پوشه را روی Runflare آپلود کنید (پوشه‌ی `node_modules` شامل `ws` همراه است، نصب لازم نیست).
2. نسخه‌ی Node: ۱۸ یا بالاتر (۲۰ پیشنهاد می‌شود). دستور اجرا: `node server.mjs` (یا `npm start`).
3. **دیسک دائمی:** اگر Runflare دیسک/Volume دائمی دارد، آن را به مسیری وصل کنید و متغیر `DATA_DIR` را روی همان مسیر بگذارید.
   بدون این کار، با هر دیپلوی یا ری‌استارت ممکن است همه‌ی داده‌ها پاک شود. حتماً مرتب از «پشتیبان‌گیری» داخل پنل بک‌آپ بگیرید.
4. بررسی سلامت: آدرس `/healthz` باید `ok` بدهد.

## انتقال داده از کلودفلر
در پنل قدیمی «پشتیبان‌گیری» → خروجی بگیرید، در پنل جدید «بازیابی» کنید. رمز ورود به‌صورت پیش‌فرض منتقل نمی‌شود (در پنل جدید رمز تازه بسازید).
اگر وب‌هوک ربات‌های تلگرام/روبیکا/بله را قبلاً روی آدرس کلودفلر ثبت کرده‌اید، یک‌بار از پنل برای آدرس جدید دوباره ثبت کنید.

## محدودیت‌ها
- `env.AI` (هوش مصنوعی خود کلودفلر) روی Node وجود ندارد؛ فقط Gemini/Groq/TokenHarbor با کلید خودشان، و آن‌ها به اینترنت بین‌الملل نیاز دارند.
- مدل OCR فارسی داخل بسته است و محلی کار می‌کند.
- حافظه‌ی اتاق‌های کلاس/وبینار (تخته و چت زنده) مثل کلودفلر در RAM است و با ری‌استارت سرور پاک می‌شود.
