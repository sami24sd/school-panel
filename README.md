# پنل معلم روی رانفلر (Runflare)

این پوشه همان `index.js` پنل را روی Node.js اجرا می‌کند؛ `index.js` هیچ تغییری نکرده و نسخه‌ی کلودفلر شما همان‌طور که هست می‌ماند.

## فایل‌ها
- `index.js` : کد پنل (نسخه‌ی جدیدش را هر وقت گرفتید همین فایل را جایگزین کنید و سرویس را ری‌استارت کنید).
- `server.mjs` : اجراکننده (Worker را روی Node بالا می‌آورد، WebSocket کلاس آنلاین را پل می‌زند، فونت‌ها و کتابخانه‌ها را از `assets/` می‌دهد).
- `assets/` : فونت‌ها و کتابخانه‌های محلی (تا بدون اینترنت بین‌الملل کار کند).
- `package.json` / `package-lock.json` : وابستگی‌ها.
- `Dockerfile` : اگر رانفلر پروژه را با Docker بسازد از آن استفاده می‌شود.

## مراحل
1. **پروژه بسازید** در رانفلر (نوع Node.js یا Docker). دستور شروع: `npm start`. پورت برنامه: `8080` (یا مقدار متغیر `PORT`).
2. **پوشه را آپلود کنید** (با CLI رانفلر یا روشی که پنل رانفلر می‌دهد). `node_modules` را آپلود نکنید؛ رانفلر خودش `npm ci` می‌زند.
3. **دیسک اضافه کنید (خیلی مهم):** در بخش دیسک‌ها یک دیسک به سرویس وصل کنید، مثلاً روی مسیر `/data`.
4. **متغیرهای محیطی** را بگذارید:
   - `DATA_DIR=/data` ← بدون دیسک، با هر دیپلوی همه‌ی داده‌ها پاک می‌شود.
   - `PUBLIC_ORIGIN=https://آدرس-دامنه-شما` ← آدرس عمومی سایت.
5. **دامنه:** در بخش دامنه‌ها دامنه را اضافه کنید، DNS را طبق راهنمای رانفلر تنظیم کنید، دامنه را به سرویس وصل کنید و SSL رایگان را فعال کنید.
6. آدرس `https://دامنه-شما/teacher` را باز کنید. اولین رمزی که وارد می‌کنید رمز معلم است.

## نکته‌ها
- پلن رایگان رانفلر برای داده‌ی واقعی مناسب نیست (بک‌آپ و تضمین پایداری ندارد و بعد از مدتی حذف می‌شود)؛ پلن پولی بگیرید و از دیسک بک‌آپ بگیرید.
- DNS دامنه را روی سرویس داخلی بگذارید، نه کلودفلر، تا در شبکه‌ی ملی جواب بدهد.
- بات و اطلاع‌رسانی تلگرام و امکانات هوش مصنوعی بدون اینترنت بین‌الملل کار نمی‌کنند (بله، روبیکا و پیامک داخلی‌اند).
- این بسته روی خود رانفلر امتحان نشده؛ اگر موقع دیپلوی خطایی دیدید، متن آن را بفرستید.

## متغیرهای محیطی
| متغیر | کاربرد | پیش‌فرض |
|---|---|---|
| `PORT` | پورت سرور | `8080` |
| `DATA_DIR` | محل ذخیره‌ی داده‌ها | `./data` |
| `PUBLIC_ORIGIN` | آدرس عمومی سایت | از خود درخواست خوانده می‌شود |
| `LOCAL_ASSETS` | `0` یعنی آدرس‌های CDN جایگزین نشود | روشن |
| `GROQ_API_KEY` / `GEMINI_API_KEY` | کلید هوش مصنوعی (اختیاری) | خالی |
